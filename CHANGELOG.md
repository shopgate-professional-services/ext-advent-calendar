# Changelog

## 2.0.0

### Changed
- Requires PWA 7 (`@shopgate/engage` 7.x). PWA 6 is no longer supported.
- Development dependencies updated to the PWA 7 toolchain (`@shopgate/engage` 7, `@shopgate/eslint-config` 7, ESLint 8).
- Today's calendar door can be opened with the keyboard (Enter / Space).

### Fixed
- Development toolchain no longer references `@shopgate/engage` 6.

## 1.1.2

### Fixed
- Removed `peerDependencies` that blocked deployments with newer PWA versions.
